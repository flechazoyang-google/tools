## 一、重写目标与原则

| 原则        | 说明                                                             |
| --------- | -------------------------------------------------------------- |
| 功能做精不做堆   | 不追 100+ 工具数量，聚焦高频、可完全离线、无版权风险的工具，首版约 24 个，按优先级分批交付             |
| 架构强制统一    | 全部工具强制 Screen + ViewModel + UiState 三件套，消灭"Screen 里写业务逻辑"的历史包袱 |
| 本地优先      | 除汇率/IP/更新检查外全部离线可用，无广告无追踪                                      |
| 注册中心保留并升级 | ToolRegistry 模式经过验证，重写为声明式元数据（分类/关键词/权重），驱动首页、搜索、分类、收藏         |
| 数据可迁移     | 提供旧版 Toolbox 数据导入（倒数日、密码、经期），用户无缝升级                            |

### 优先级定义

- **P0（阶段一 · MVP，12 个）**：计算器、单位换算、汇率、九宫格、二维码（生成+扫描）、Base64、时间戳、倒数日、番茄钟、搜索/收藏、主题系统
- **P1（阶段二 · 完整版，10 个）**：BMI(升级)、图片压缩、拼接、取色器、水印、拼豆图纸、文本差异、密码生成器、亲戚称呼、经期、尺子、水平仪、指南针
- **P2（阶段三 · 增值，4 个）**：金额大写、做个决定、手持弹幕、设备信息

### ❌ 明确不做

- 去水印（本地 inpainting 效果差，第三方 API 有合规风险）
- OCR（ML Kit 中文包体积 +60MB，与"轻量"定位冲突，P2 再评估）
- 传感器不可用机型的降级提示会统一内置在测量类工具中

```
┌─────────────────────────────────────┐
│  首页          工具          我的    │   ← 底部导航 3 Tab
│                                     │
│  首页：大标题问候语                  │
│   ├ 搜索框（全局工具搜索）           │

│  工具：全部分类列表                  │
│   └ 左侧分类锚点 + 右侧工具列表      │
```

- 导航层级压缩为 **Tab → 工具页** 两级，工具内二级页面不超过一层
- 页面转场统一采用 **共享轴（Shared Axis）** 动效
- 每个工具页统一结构：TopBar（返回+标题+右上操作）→ 内容区 → 底部操作栏（如有）

## 四、视觉设计规范

### 色彩（Material 3 动态取色 + 固定种子色兜底）

| Token                 | 亮色                | 暗色                | 用途           |
| --------------------- | ----------------- | ----------------- | ------------ |
| primary / onPrimary   | 种子色 40 / 100      | 种子色 80 / 20       | 主操作、选中态      |
| primaryContainer / on | 90 / 10           | 30 / 90           | 卡片强调、Chip 选中 |
| surface / onSurface   | #FDFBF7 / #1C1B1F | #1C1B1F / #E6E1E5 | 页面底色/正文      |
| surfaceContainer      | #F3F0EA           | #2B2926           | 工具卡片         |
| outlineVariant        | 0.8 alpha 灰       | —                 | 分隔线、描边       |

- **种子色**：暖青 `#2E6E5E`（沉静工具感，与旧版紫区分，区分度测试后可调）
- Android 12+ 读取用户壁纸动态取色，低版本回落固定种子色
- 分类色仅用于图标底色（6 分类 6 个 90 阶浅色），**全局只有 1 个彩色 ramp，避免花哨**

### 字体与形状

- 字体层级：Title-L 22sp / Title-M 16sp / Body 14sp / Label 12sp，全部 system sans
- 圆角体系：卡片 16dp / 输入框 12dp / Chip 8dp / 按钮 100dp（全圆角）
- 间距体系：4 的倍数（4/8/12/16/24/32），页面水平边距 16dp
- 图标：Material Symbols Rounded 全家桶，分类图标 20dp 内缩于 40dp 圆角底
- 深色模式：一等公民，纯灰阶推导（M3 tonal palette），禁止硬编码色值

## 五、技术架构

```
com.flechazo.toolbox          ← 新包名（替换 com.example.*）
├── app/                      入口、导航、DI 装配
├── core/
│   ├── designsystem/         主题、色彩、组件库（ToolCard/TopBar/EmptyState…）
│   ├── registry/             ToolRegistry 2.0（元数据声明 + 延迟组装）
│   ├── data/                 Room + DataStore 统一封装
│   └── util/                 格式化、加密、导出导入
└── feature/
    ├── calculator/ unit_converter/ currency/ …  每工具一包
    └── （包内固定：XxxScreen + XxxViewModel + XxxUiState）
```

- **技术栈**：Kotlin 2.0 + Compose BOM + Material3 + Hilt(KSP) + Room + DataStore + Retrofit + WorkManager，minSdk 26 / target 35
- **数据迁移**：首启检测旧版 `com.example.toolbox` 数据（Room db + DataStore），提供一键导入，导入完成后原数据保留不删
- **质量底线**：R8 混淆开启、所有 ViewModel/算法层（换算表、农历、diff、亲戚关系树）JUnit 单测、Room 显式 Migration（禁用 destructive fallback）
- **密码箱**：若确认保留，认证层从 SHA-256 升级为 PBKDF2-SHA256 + 随机盐（10 万次迭代），Keystore 加密逻辑重写复用
