# Toolbox v1.1.0 发布说明

> 版本：1.1.0（versionCode 2）
> 基线：v1.0.0 重写版
> 主题：**生产级修复**——修正算法错误、消除崩溃与内存风险、补齐计划承诺的功能

---

## 一、修复的正确性缺陷（会算错 / 显示错）

| 工具 | 问题 | 修复 |
|---|---|---|
| 金额大写 | `((amount-yuan)*100).toInt()` 浮点截断，`8.10`→"玖分"、`1234.56`→"伍角伍分"；分节处丢"零"，`10001`→"壹万壹" | 改用 `BigDecimal` + `HALF_UP` 取到分，重写零插入算法；新增 9 个单测 |
| 单位换算 | 开尔文→华氏落入 `else` 分支，算成 `value-273.15` | 补显式分支，未覆盖组合返回 `NaN` 而非静默错误 |
| 时间戳 | 相对时间方向相反：过去显示"5 分钟后" | 过去→"x 前"，未来→"x 后"；抽成纯函数并加单测 |
| 倒数日 | 纪念日显示"已 -1699 天"；明天显示"还剩 2 天" | 重写 `countdownLabel`，纪念日/倒数日分别取绝对值与正确天数 |
| 经期记录 | `DatePicker` 初值按 UTC 解释，UTC+8 凌晨会记录成昨天 | 初值改为"当天 00:00 UTC" |
| 计算器 | 出错后表达式本身被覆盖成"错误"，只能 AC；键盘没有括号键却宣称支持括号；`%` 是取模 | 保留原表达式并置错误态；新增 `(` `)` 键与历史记录；`%` 改为后缀百分号（`200×10%=20`） |
| 小数点区域 | `"%.2f".format()` 受系统 Locale 影响，逗号小数点导致 BMI 消失、计算器表达式被污染 | 所有机器可回读的格式化统一 `Locale.ROOT`；`tokenize` 不再静默丢弃逗号 |
| 汇率 | "常见货币对"标题把金额中的小数点过滤掉（1.5 显示成 15） | 直接使用原始金额 |

## 二、消除的崩溃与内存风险

- **图片采样逻辑错误**：旧循环只会把图片压到 `[maxSide, 2×maxSide)`，4032×3024 的照片在 2048 上限下完全不降采样（48.8 MB）。改为标准实现并降到 1600px 预览上限。
- **九宫格**：全分辨率解码 + `!!` 空指针 + 尺寸为 0 时崩溃 → 统一走 `ImageUtils.loadScaled`，最后一行/列吸收余数像素（不再丢边），新增"带白边"导出选项。
- **拼接**：输出高度无上限（9 张可达 36855px ≈ 302 MB）→ 计算尺寸前先校验 4000 万像素 / 单边 16384px 上限，超限拒绝并提示；新增缩略图删除/排序与间距滑杆。
- **拼豆**：导出位图无上限 → 上限 1600 万像素并按需缩小格子，超限拒绝；透明像素先合成白底（不再变成黑豆）；网格改用最近邻采样（不再出现调色板错配）；新增调色板下拉与双指缩放。
- **取色器 / 加水印 / 二维码**：全分辨率解码 → 统一下采样；均补错误态与加载态。
- **二维码**：超过 QR 容量直接抛异常崩溃 → 编码前按 UTF-8 字节数预检（上限 2953）；"长按保存"假提示改为真实的保存按钮。
- **相册保存**：写入前标记 `IS_PENDING`、失败时清理占位行、检查 `compress()` 返回值；不再出现 0 字节条目或"假成功"。
- **EXIF 方向**：所有解码路径现在按 `TAG_ORIENTATION` 旋转，相机照片不再横躺。
- **JPEG 透明**：压缩前合成白底，透明 PNG 不再变黑。
- **任务竞态**：九宫格 / 压缩 / 水印 / 拼接 / 拼豆 / 二维码均加入 `Job` 取消与结果令牌，旧任务不会覆盖新结果。
- **主线程 I/O**：设备信息、经期记录、文本对比（O(n·m) DP 表）移出主线程。
- **文本对比**：新增 2000 行上限与 500ms 防抖，避免 ANR 与内存爆炸。

## 三、补齐的计划承诺

- **倒数日提醒**：新增通知渠道 + `AlarmManager` 当天 09:00 提醒 + API 33 运行时权限申请 + `CountdownAlarmReceiver`。
- **经期月历**：新增月视图（点击记录/取消、预测日描边、今日加粗）、三行预测详情；存储从裸 `SharedPreferences` 迁移到 DataStore + Repository；预测改用中位数抗异常值。
- **番茄钟**：计时改为锚定 `SystemClock.elapsedRealtime()`（不再漂移），阶段自动衔接不再停在边界，当日统计落 DataStore，新增阶段切换与轮次指示点，环色按阶段区分。
- **做个决定**：转盘现在真正绘制选项文字（旧代码只算了坐标），`isSpinning` 由 ViewModel 计时兜底（不会永久卡死），新增抽签 / 随机数两种模式与历史结果。
- **手持弹幕**：全屏状态移入 UiState（转屏不再退出），真沉浸式隐藏系统栏、屏幕常亮，滚动距离按实际文字宽度计算（长文本能完整走完）。
- **密码箱**：退到后台自动锁定；新增搜索；复制密码在 API 33+ 标记为敏感内容（避免剪贴板预览泄露）。
- **设备信息**：补齐 CPU（平台/核心数/最高频率/ABI）与传感器列表，读取移出主线程，新增刷新按钮。
- **亲戚称呼**：新增"对方怎么叫我"反推（含性别开关），覆盖直系、祖辈、叔伯姑舅姨、侄甥、堂表亲。
- **旧数据迁移**：修复密码导入永远为 0 条的缺陷（`pendingPasswords` 从未赋值）；改为无状态调用并避免用错误主密码覆盖既有密码箱。
- **我的页面**：新增数据导出（与旧版备份格式兼容，可再次导入）与关于/隐私说明。

## 四、设计系统与体验

- 补齐 `surfaceContainerLow` 等缺失的色彩 token——此前 `ToolCard`/`ToolSectionCard` 会回落到 Material 3 默认的偏紫色，与暖色主题冲突。
- 深色模式状态栏图标跟随应用主题（新增 `values-night/themes.xml`），冷启动不再白闪。
- 尺子刻度改用主题色（深色模式下此前几乎不可见）。
- 番茄钟、决策转盘、BMI 色带、文本对比配色全部改为主题 token。
- `ResultCard` 新增 `singleLine` 参数：Base64 等多行结果不再被省略号截断，并支持选中复制。
- `FeedbackBlock` 补齐 Success 态；删除遗留的 `EmptyState`。

## 五、工程

- `git init` 并建立基线提交，修复过程全程可回溯。
- 单元测试从 35 个增加到 **71 个**（新增金额大写、相对时间、倒数日、经期预测、番茄钟计时、亲戚反推、图片采样、文本对比上限）。
- 新增依赖：`androidx.exifinterface:exifinterface:1.3.7`（约 60 KB）。
- Release 包：**2.08 MB**（R8 + 资源压缩），`assembleRelease` 与 `testDebugUnitTest` 均通过。

## 六、已知限制

- 二维码仅支持相册识码，未接入相机实时扫码（避免引入 CameraX/ML Kit 体积）。
- 倒数日提醒使用非精确闹钟（`AlarmManager.set`），可能存在数分钟偏差；这是为了免去 API 31+ 的精确闹钟授权。
- 农历 / 节假日仍不支持，旧版备份中的农历记录会被跳过并计数提示。
- UI 仍未做字符串资源化（全站中文硬编码），未接入多语言。
- 图片工具未做横屏双栏与平板 max-width 适配。
