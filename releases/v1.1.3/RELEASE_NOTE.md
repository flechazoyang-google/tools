# Toolbox v1.1.3

发布日期：2026-09-09
Version Code：5

## 变更内容

**经期记录全面重做**

- ✨ **记录更准**：数据模型从"经期开始日集合"升级为"周期（起止 + 每日经量）+ 每日症状/疼痛/备注"。连续几天补记不再被当成多次经期。
- ✨ **预测更诚实**：改为给出"预测区间 + 置信度"，依据最近 6 个周期的加权平均与你的真实周期波动；不再给一个假装准确的日期。
- ✨ **迟到会说**：预计推迟会如实提示（如"预计已推迟 12 天"）；超过一个周期没有记录会提示"疑似漏记"。
- ✨ **日历更清楚**：区分已记录经期 / 预测经期 / 预测区间 / 易孕期 / 估算排卵日 / 今天，并补齐图例与读屏描述。
- ✨ **新增能力**：周期摘要与最近 6 个周期趋势图、删除可撤销、一键"记录今天"、经期数据导出/导入（JSON）、一键清空全部记录。
- 🔒 **隐私**：首次进入增加敏感个人信息告知与单独同意；经期数据只保存在本机。

**缺陷修复**

- 🐛 修复经期统计错误：连续点击多天会显示错误的"平均周期"与"已记录次数"（例如 3 次经期显示成 15 次）。
- 🐛 修复经期推迟时仍显示"还有 N 天"的问题（原逻辑会把预测日强行推到未来，迟到的信号被吞掉）。
- 🐛 修复经期数据实际会进入云备份的问题（备份排除路径仍指向旧的存储文件），同时排除换机迁移。

**其他**

- 🛠 搜索"月经""例假""大姨妈""安全期""排卵期"等词现在都能找到经期记录。
- 🛠 旧版本记录自动无损迁移（连续日期会合并为一次经期）。
- 🛠 新增 29 个单元测试（累计 101 个）。
