# Toolbox v1.2.0

发布日期：2026-09-10
Version Code：6

## 变更内容

**倒数日全面重做**

- ✨ **生日终于可以每年自动倒数了**：事件支持「不重复 / 每周 / 每月 / 每年（公历）/ 每年（农历）」。生日、结婚纪念日、忌日设一次就行，过了自动转到下一年，不用每年手动改日期。
- ✨ **支持农历**：可按农历日期倒数（如"农历八月十五""正月初一"），卡片同时显示农历与公历。闰月生日按民间习惯处理：那年没有闰月就按同月同日过，并会明确告诉你"实际按哪天"。
- ✨ **改完了，不用删了重建**：点卡片即可修改名称、日期、重复规则、提醒、颜色、备注（之前只能删掉重加）。
- ✨ **删除可撤销**：误删后底部会出现"撤销"，原来的编号和创建时间都保留（正数日子的天数不会因为一次误删而算错）。
- ✨ **重启手机后，提醒照样送达**：新增开机与时区变更后的自动重排，另有每日后台自检兜底。之前闹钟会随重启或改时区静默消失。
- ✨ **多档提前提醒**：可选当天、前 1/3/7/30 天（可多选），提醒时间自选（默认 09:00）。
- ✨ **更顺手的整理**：默认按"临近优先"排列（今天和最近的排最前），支持置顶、按创建时间与名称排序，以及「全部 / 只看置顶 / 只看农历」筛选。
- ✨ **首屏更醒目**：置顶或最近的事件会以大数字主卡呈现；天数很多时（如上万年）自动缩小字号而不溢出；长日子支持"年 + 月 + 日"分解与进度条。
- ✨ **跨过零点自动更新**：App 一直开着等到第二天，天数会自己翻篇，不需要退出重进。
- 🎨 每个事件可选主题色（8 色），深色模式一并适配。
- 🔒 提醒通知在锁屏上可显示但内容私有，解锁后才展示事件名称与内容。

**缺陷修复**

- 🐛 修复事件过期后显示"还有 -12 天"的问题（现在正确显示"已过 12 天"，正数日子与倒数不再混在一起）。
- 🐛 修复每月 31 号、2 月 29 号这类"这个月没有这天"的重复规则：自动回落到当月最后一天，而不是跳到下个月或消失。
- 🐛 修复农历数据源错误：旧坊间通用历表在 1933、1996、2060 年把月份大小记反，会导致这一年里部分农历日期整体错位一天。本次已按香港天文台官方年历逐年核对修正（201 年逐月长度全部复核通过）。
- 🐛 修复从旧版本备份导入时，1970 年之前的日期（祖辈生日）被整条丢弃的问题。
- 🐛 修复导入旧备份时农历事件被跳过、以及重复导入产生双份事件的问题。

**其他**

- 🛠 升级自动完成，**已有事件一条不动**：名称、日期、颜色、置顶、提醒设置全部保留，原设为"当天 09:00 提醒"的老事件升级后仍按当天 09:00 提醒。
- 🛠 数据备份/恢复升级为 v2 格式（字段更全），同时**继续读取旧版备份文件**；换机或重装后导入即可。
- 🛠 搜索"生日""农历""纪念日""周年""预产期""days matter"等词现在都能找到倒数日。
- 🛠 长按卡片即可置顶/取消置顶；读屏会完整朗读事件名称、日期与剩余天数。
- 🛠 新增 84 个单元测试（累计 185 个），重点覆盖重复规则边界、农历换算、提醒排期与备份兼容。
